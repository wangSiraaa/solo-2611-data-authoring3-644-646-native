# 有界租约与流量观察材料

`case.json`提供一个小地址池、按顺序执行的管理员请求和可乱序接收的累计流量观察。它不是完整DHCP/IPFIX协议或生产网络资料。

管理员请求中的`save_as`和`offer_ref/lease_ref`是演示脚本引用前一真实返回ID的变量名，不是要求服务生成这些固定token；offer_id/lease_id由你的实现实际产生。`pool`含10.0.0.2与10.0.0.10，数值排序不可误作字符串排序。时刻和计数均为非负整数。

`observations`可以先整批接收，然后分别选择只有A租约的快照及包含B租约的新快照build。只有租约服务真实产生/导出的快照可作为本服务演示；外部快照测试另按题面公开JSON合同准备。样例覆盖计量边界与跨换租，全部正确性范围仍以题面为准。材料没有服务源码、内部审核、预期结果或调用数要求。
