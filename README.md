# 换汇成交与应收事实仓起点

Python 3.11，当前两个小原型可直接导入；没有外部服务和隐藏依赖。
quote_source.py演示同小数位普通正向报价及接受，receivable.py演示普通同币种发票/回款。case.json是完整自包含的合成输入和边界场景，不含目标实现或预先算好的报告。

币种小数位来自currency_decimals，金额字段为各自币种最小单位；prices里base/quote均按主要单位报价。payment的book_rate是回款币种每主要单位折合本位币主要单位；invoice的book_rate是发票币种对应口径。整数day、request_time、accepted_at使用同一刻度。

已有原型故意只支持普通路径，没有题面要求的单位换算、完整双向报价、历史前缀、持久化、修订/贷项、整笔原子隔离与更正释放。候选可改造接口和文件布局，但须提供清楚的可运行入口并实现完整题面。金额不得通过现有原型的错误换算结果作为预期。
